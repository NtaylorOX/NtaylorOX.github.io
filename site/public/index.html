Why serving engines batch continuously

Output lengths vary a lot. A static batch waits for its longest request; a continuous batch refills a slot the moment one frees up. Hatched cells are idle slots.

A step is one decoded token for every running request. Latency is in steps, with all requests arriving at once. Real engines add scheduling overheads this ignores.

How much is a benchmark score worth?

Applies to any model or benchmark. Run one evaluation of a model with a fixed true accuracy. The shaded band is the 95% interval from resampling that run.

The resampling uses a normal approximation of the binomial, which is fine at these sizes. Comparing two models on the same items (a paired comparison) is tighter than comparing two intervals.

Why a good safety filter still floods you with false alarms

A detector scores every request. Safe traffic scores low, unsafe traffic scores higher, and you flag anything above a threshold. The catch is how rare the unsafe traffic is.

A toy model: two bell curves with equal spread, not data from any real system. The point is the base-rate effect, which holds for any filter, monitor or evaluator: tuning the threshold trades missed cases against alert fatigue, and rare events make precision collapse.
